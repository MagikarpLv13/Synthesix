# Q: How does Synthesix generate reports?

## Answer

Expanded from original query via vocab: [synthesix, generate, report, reports, history, html, search, result, results, investigation, export, view]. Synthesix generates local static reports, not server-rendered views. Search results go through SearchOrchestrator.search(), which aggregates/scored engine results, calls utils.generate_html_report(), writes history/search_results_*.html, records the run via add_to_history(), then regenerates history.html via generate_history_html(). Investigation pages are generated by main._generate_investigation_page(), which calls InvestigationService.workspace_payload() then investigations.view.generate_investigation_page(); that writes data/investigation_pages/<id>.html with Python-rendered HTML and inline JS. Local archive search uses investigations.search_view.generate_local_search_page(). Monitoring diffs use investigations.monitoring_view.generate_page_comparison_report(). ZeroNeurone exports use exports.zeroneurone.export_zeroneurone_bundle(), producing GraphML, CSV, native dossier archive, and manifest. Shared visual HTML primitives live in ui.py.
